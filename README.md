# Anupam Upadhyay

Source for [anupam128.com](https://anupam128.com): a Jekyll site for fiction, essays, and ideas.

## Edit and preview

- Add writing in `_posts/`.
- Update featured work and categories in `_data/writing.yml`.
- Adjust shared templates in `_layouts/` and `_includes/`.

To preview locally:

```sh
bundle install
bundle exec jekyll serve
```

## Deploy

GitHub Actions builds and deploys the site whenever changes are pushed to `main`.
